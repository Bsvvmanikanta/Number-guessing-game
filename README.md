# Number Guessing Game

## Project Title

Number Guessing Game using Python

## Description

This project is a simple Python-based number guessing game.

The computer generates a random number between 1 and 100.
The user has to guess the number, and the program provides
hints such as "Too high" or "Too low" until the correct number
is guessed.

The program also counts the number of attempts and handles
invalid user input.

## Technologies Used

- Python
- Random module
- While loop
- Conditional statements
- Try/Except exception handling

## Features

- Generates a random number between 1 and 100
- Provides "Too high" and "Too low" hints
- Counts the number of attempts
- Continues until the correct number is guessed
- Handles invalid input
